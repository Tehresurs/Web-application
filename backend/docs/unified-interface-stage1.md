## Экипажи

Компактный список и поиск слева, выбранный экипаж справа: водитель, телефон, автомобиль, госномер. Поиск также учитывает название экипажа. Использованы существующие `ui-card`, `ui-fields`, `ui-button`, SVG `uiIcon`. Исходные элементы поиска и добавления перемещаются без смены ID и без потери обработчиков. CRUD продолжает обрабатываться прежними делегированными слушателями на `crewList`. Изменение employees.crew_id не добавлялось.

## Объекты

Список слева, карточка выбранного объекта справа. Подобъекты отрисовывает прежний `renderObjectHierarchy`, открывается прежний редактор с проверкой и подтверждением переноса. Сохранены сортировка, фильтры наличия/активности подобъектов и поиск. Категория и ПО не являются полями объекта в текущей модели; это объяснение показано в карточке, отдельные значения не выдумываются. Архив и преобразования не добавлялись; обработчики удаления прежние.
