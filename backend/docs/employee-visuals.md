# Сотрудники — визуальная доводка

04.10.2026. Добавлены цветные chips таблицы, усиленное выделение выбранной строки, два цветных индикатора шапки, локальные SVG-иконки, активные вкладки с фоном, акценты карточек, отдельный блок текущего состояния и четыре быстрых действия.

Цвет свободной причины определяется наличием активного отсутствия, а не словарём названий. Значения дней получаются из прежнего расчёта; неактивный период показывается как 0 только при известном противоположном состоянии с числовой длительностью. Недостающие данные остаются «—».

Быстрые действия открывают существующие: календарь выбранного сотрудника, форму движения, форму «Другое», форму согласованного исключения. Новых API и расчётов нет. Основное меню не менялось.
