# Сотрудники — список и карточка

Выполнено 04.10.2026. Изменён только интерфейс сотрудников; backend, БД, API и расчётные сервисы не менялись.

Изменены `app/templates/processing.html` и `app/static/js/processing.js`. Созданы `app/static/js/employee_workspace.js`, `app/static/css/ui_components.css`, `tests/test_employee_workspace.cjs`, `tests/browser/employee_workspace.cjs` и этот отчёт.

Общие классы: `ui-page-header`, `ui-section-header`, `ui-card`, `ui-tabs`, `ui-tab`, `ui-table`, `ui-table-wrap`, `ui-button`, `ui-button-primary`, `ui-input`, `ui-badge`, `ui-empty`, `ui-fields`, `ui-stack`, `ui-error`. Они не привязаны к ID сотрудника. Тёмно-синяя навигация применяется только при открытой странице сотрудников; остальные экраны не переведены на новый стиль.

Слева — поиск по ФИО, должности, телефону, НРС (сохранён и поиск по экипажу), фильтры статуса, места и графика. Отдельно сохранены архив, восстановление и просмотр всех сотрудников. Таблица имеет шесть колонок и выделение выбранной строки. Справа — постоянные реквизиты, статусы, кнопки редактирования и архивирования.

Подвкладки:

- Основные данные: личные данные, увольнение, параметры должности, специальность, персональные максимальные сроки, текущая длительность из существующего API месячного ЛУВР.
- История: существующие перемещения, периоды болезни, согласованные исключения; управление открывает прежний блок истории в форме сотрудника.
- Экипаж и объекты: водитель, телефон, автомобиль и существующие назначения с ПО/категорией; изменение через прежнюю форму.
- Оборудование и ТМЦ; Обучение и аттестация: только «Раздел будет добавлен позже».

Ограничения существующих данных отображаются явно: для сотрудника вне текущего месячного ЛУВР API не возвращает длительность, поэтому карточка сообщает об отсутствии расчёта. Новый расчёт или endpoint не добавлен. Назначения связаны с объектами, отдельной связи сотрудник–подобъект в текущем API нет; карточка не приписывает сотруднику все подобъекты родительского объекта.

- Frontend: 164 теста прошли, включая 3 новых теста поиска/фильтров/статуса и существующий Chrome-тест прокрутки модальных окон.
- Изолированный Chrome-сценарий: добавление, редактирование, увольнение, архивирование, восстановление, поиск по НРС, фильтры, выбор строки, все пять вкладок; без JS-исключений. Рабочие данные не изменялись.
- Read-only Chrome-сценарий на рабочих сотрудниках: список, фильтры, история, экипаж/назначения, совпадение текущих дней с ответом ЛУВР.
- Адаптивность: 1920, 1366, 900 и 390 px без горизонтального переполнения всей страницы. На узких экранах карточка под списком; таблица прокручивается внутри своего контейнера.
