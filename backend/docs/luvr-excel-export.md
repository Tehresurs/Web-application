# ЛУВР: итоги по датам и Excel

Завершено 03.10.2026 с учётом уточнения пользователя: из MASTER берём шапку и подписантов; тело таблицы формируем из рассчитанного месячного ЛУВР. Это уточнение заменяет прежнее требование сохранять старые строки и формулы заполненной книги.

## Результат

В месячном ЛУВР добавлена кнопка «Выгрузить Excel», активная для сформированного месяца. GET `/api/luvr/month/export?year=2026&month=10` возвращает новый xlsx. Для несформированного/пустого месяца, ошибочной конфигурации сотрудника или неподходящего шаблона возвращается 400 с понятным сообщением.

Источник — существующий `month_calendar`, без нового расчёта календаря. Состав — только month membership. Порядок — полное ФИО по алфавиту, затем employee_id; сортировка UI не влияет. Строки динамические, ограничение старого шаблона в 76 сотрудников снято. ФИО и прочие строки записываются текстом, а не Excel-формулами.

FULL → число 1; HALF → число 0.5; TRAVEL → Д; OFF_SHIFT → МВ; DOWNTIME → П; DISMISSED → Уволен; EMPTY → пустая ячейка. Больничные и UNKNOWN остаются пустыми по итоговому календарю. Старую легенду «П — прогул» не переносим: она не входит в согласованные шапку и подписантов. Override и его отмена сразу учитываются при следующем скачивании.

## Шаблон и mapping

MASTER: `C:\Projects\Билеты\ЛУВР ООО Салым Петролеум Девелопмент rev1.xlsx`. Можно задать другой путь через `LUVR_TEMPLATE_PATH`; файл должен иметь согласованные шапку и подписантов. Используется openpyxl 3.1.5, загрузка существующего workbook в память. MASTER никогда не сохраняется.

Проверенная версия содержит один лист «Октябрь». Сохраняем шапку строк 1–8, её оформление и 12 объединений. Период в F7 и даты F8:AJ8 заполняются выбранным месяцем. Название выходного листа YYYY-MM. Для отсутствующих дней календарные клетки и заголовки пустые; все 31 колонка сохраняются.

| Данные | Область результата |
|---|---|
| № / ФИО / должность / НРС / специальность | A / B / C / D / E, начиная со строки 9 |
| Дни 1–31 | F:AJ |
| Рабочие дни / простой / дорога | AK / AL / AM |
| Дневные итоги | 10 строк сразу после сотрудников |
| Подписанты | после итогов с отступом, из строк MASTER 90 и 93 |

Оформление строк сотрудников берётся из строки 9, итогов — из строки 85. Подписи «Разработал», должность и ФИО разработчика, «Согласовано», должность согласующего сохраняются из MASTER. Случайные значения в промежуточных строках подписантов не переносим.

Старые сотрудники, даты, заметки, формулы C72:E72 и AK87 не копируются. Старые формулы итогов заменены готовыми monthly totals: Excel не требует пересчёта и не создаёт самостоятельный calculation layer. Новый размер таблицы определяет область печати и автофильтр. Ширины колонок и оформление шапки сохранены; печать по ширине одной страницы, высота по содержимому; закрепление F9, повторение строк 7–8 на печати. Старые разрывы страниц убраны.

## Дневные итоги

Считаются по FINAL только сотрудников состава месяца: full_count, half_count, travel_count, off_shift_count, downtime_count, dismissed_count. Отдельно sick_count и unknown_count. Присутствуют = FULL + HALF; эквивалент = FULL + HALF × 0.5. Выходной 5/2 не считается UNKNOWN. Эти же десять показателей экспортируются под соответствующими датами. В вебе итоговые строки находятся внутри той же таблицы и синхронно прокручиваются.
