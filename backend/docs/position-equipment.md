# Оснащение специалиста по должности

12.10.2026.

Миграция `022_position_equipment.sql` добавляет nullable `positions.equipment_description TEXT`, без DEFAULT и автоматического заполнения. Runner `python -m app.database.migrate_position_equipment` выполняет её транзакционно с advisory lock и проверкой неизменности всех прежних полей. Рабочая миграция и повторный запуск прошли: 18 должностей, у всех новое поле NULL. Старые миграции не изменялись.

Существующие GET/POST/PATCH `/api/positions` читают и сохраняют новое поле. Пропуск поля при PATCH сохраняет прежний текст; null и пустая строка разрешены. Пробелы и переносы не обрезаются. Форма должности использует существующее сохранение, добавлен textarea «Оснащение специалиста».

Общий сервис расстановки получает оснащение через JOIN сотрудника с positions. Одно значение повторяется во всех объектных строках сотрудника, включая строку без конкретного объекта. Пустое поле даёт пустую ячейку. Прежние автоматические «Набор ВИК, Линейка, Рулетка» и «Необходимость отсутствует» удалены из правила заполнения. Сортировка, PLAN/FACT, строки и итоги не менялись.

Excel получает тот же текст из готового отчёта. wrap_text сохранён, оценка высоты строки учитывает явные переводы строк. Семь колонок и договорная структура прежние.
