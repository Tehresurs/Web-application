## Несовместимости, требующие решения до реализации экспорта

1. Для экспорта любого месяца нельзя однозначно выбрать лист: отсутствуют ноябрь/декабрь, вместимость ранних листов существенно меньше октября. Предлагается использовать оформление «Октябрь» как универсальную основу и заполнять только этот лист в копии книги, сохраняя остальные листы. Если состав больше 76 — отклонять экспорт, не расширять структуру без отдельного согласования. Имя листа при таком решении останется «Октябрь», период будет определяться AO5/AQ5; это нужно явно согласовать либо утвердить иной вариант книги.
2. C72:E72 — формулы ссылок на C68:E68. При заполнении произвольным составом они дают параметры другого сотрудника. Предлагается разрешить замену только этих трёх формул значениями соответствующего сотрудника в экспортной копии. Расчётные формулы итогов сохранять.
3. AK87 содержит `=AK85-AK43-AK42-AK41-AK38-2`. Значение зависит от конкретных номеров строк старого состава. При новом составе или сортировке смысл не сохраняется. Нужна расшифровка назначения и решение о сохранении/очистке/замене; формулу самостоятельно не менять.
4. Легенда A96 определяет «п» как простой, A100 определяет «П» как прогул. Задание требует DOWNTIME → «П». Это смысловой конфликт с утверждённой легендой. Предлагается для Excel использовать DOWNTIME → «п», сохранив веб-код и легенду; альтернативно требуется разрешение изменить легенду копии.
5. На октябрьском листе сотрудники сгруппированы по специальностям; общий алфавит не соблюдён. Официальный порядок нужно определить при согласовании универсального листа. Временная сортировка UI в экспорт не переносится.

До решения этих вопросов export-код и кнопка скачивания не добавлены. Готовые итоги по датам не менялись. MASTER и БД не изменялись. Предыдущие результаты тестов дневных итогов: 309 backend и 156 frontend; на этом шаге тесты повторно не запускались, поскольку изменена только документация.
