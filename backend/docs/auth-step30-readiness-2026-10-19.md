## Сессии, cookie, CSRF, вход

- Argon2id: time_cost=3, memory_cost=65536 KiB, parallelism=1. Механизм первоначального пароля требует 16..1024 символа.
- Токен сессии: secrets.token_urlsafe(32), только SHA256 в БД; token в JSON не возвращается.
- Абсолютный срок сессии 8 часов; cookie Max-Age=28800, HttpOnly, SameSite=Strict, Path=/, без Domain.
- Secure включён при HTTPS. На текущем loopback HTTP Secure=False — предусмотренное локальное исключение. Это не готовая конфигурация доступа из интернета.
- Изменяющие запросы: проверка той же Origin и HMAC-CSRF, привязанного к сессии, сравнение constant-time. UI хранит CSRF только в памяти.
- Выход отзывает сессию и удаляет cookie; блокировка пользователя, архив сотрудника, истечение и credential_version проверяются при получении пользователя. Возврата к LEADER нет.
- После 10 неудачных попыток за 15 минут по аккаунту или peer дальнейший вход ограничивается; события сохраняются в БД, конкурентные попытки сериализуются advisory locks.
- Скользящего/idle срока и обязательной смены первоначального пароля сейчас нет. Если потребуется одноразовый пароль/сброс по ссылке, это отдельная функция с отдельным планом, не скрытая часть нынешнего запуска.
- Перед будущим Tunnel отдельно проверить HTTPS, доверенные proxy headers, реальный peer/IP и лимиты при нескольких пользователях за прокси. Сейчас Tunnel/Access не настраивались.
