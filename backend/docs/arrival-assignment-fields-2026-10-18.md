# Редактирование категории и ПО в матрице — 18.10.2026

Актуальное поведение: отдельные кнопки «Добавить категорию» / «Изменить категорию»
убраны. Категория и ПО отображаются одним нажимаемым полем, как «Режим контроля».
Нажатие открывает существующий редактор строки со списками справочников.
Для изменения на конкретную дату сначала выберите дневную ячейку.

Работа выполнена только в C:/Projects/excel-ai-agent-8001.
Действующий сервер 8001 использует ai_excel_agent_test,
схему test_construction_identity_stage46, launcher C:/Projects/run_report_review_8001.py.
Проект и сервер 8000 не изменялись.

## Как пользоваться

1. Матрица → раскрыть сотрудника → нажать на значение «Категория» или «ПО».
2. Выбрать значение из списка. Сохранение выполняется сразу через существующий
   API корректировок и перезагрузку данных матрицы.
3. Для FACT изменение относится к конкретному факту/дате; для PLAN действует
   с выбранной даты внутри существующего исходного периода.
4. При закрытии/повторном открытии значения возвращаются из сервера.
5. Формирование нового назначения заезда, добавленное ранее, сохранено:
   Билеты → подтверждённый заезд → Объект, ПО, Категория → «Сохранить назначение».

Редактируется привязка к существующим справочникам. Новые категории/ПО
в справочники из матрицы не создаются. Значения пользователю не подбирались
автоматически; никаких пользовательских корректировок при проверке не сохраняли.

## Хранение изменений ПО

Используется существующая таблица production_matrix_overrides.
Добавлена миграция **030_matrix_po_override.sql**:

- nullable po_id с FK на po_types;
- разрешено field_name='PO';
- ограничение требует для PO только po_id, для CATEGORY только category_id,
  для CONTROL_MODE только control_mode;
- старые значения, версии, источники и корректировки сохранены.

Миграция применена только после проверки точного имени БД и схемы 8001.
Проверены количества и отпечатки существующих записей до/после изменения
структуры; ежедневные отчёты, билеты, назначения и их строки не переписывались.
Миграция также подключена к установщику таблицы корректировок для новых
изолированных схем. Повторное применение проверено тестом.

PATCH /api/employees/{employee_id}/production-matrix-overrides принимает
field_name='PO', po_id и обычные scope, source identity, effective_from,
basis_revision, version. ПО проверяется по справочнику. Версия PO независима
от версии категории и режима. Недостоверный источник, неверное ПО и устаревшая
версия не сохраняются.

В дневной ячейке возвращаются фактически действующие po_id/po_name и
edit_target.fields.PO. Сам исходный daily_control_results.po_id не изменяется.
Начальные значения production_assignment_items.po_id не переписываются.
Доли, округление, суммы и ЛУВР не пересчитываются по новым правилам.
